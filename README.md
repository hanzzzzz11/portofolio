# 🌐 Portfolio Website

## 🧠 Deskripsi

Website portfolio pribadi yang menampilkan informasi tentang saya, skill, dan project yang pernah saya buat. Website ini dibuat menggunakan HTML, CSS, dan sedikit JavaScript.

---

## 🚀 Fitur Utama

* 📄 Halaman About Me
* 🛠️ Daftar Skill
* 💼 Portfolio / Project
* 📞 Contact / Sosial Media
* 🎨 Tampilan responsive (bisa di HP & laptop)

---

## ⚙️ Teknologi yang Digunakan

* HTML5
* CSS3
* JavaScript
* GitHub Pages (hosting)
